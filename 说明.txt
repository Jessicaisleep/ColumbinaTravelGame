========================================================
哥伦比娅的旅行 · 当前版本玩法说明
========================================================

这是一个可以离线运行的浏览器小游戏。

哥伦比娅住在挪德卡莱的家园。你可以照顾田地、准备料理、摆放玩具，
也可以送她前往提瓦特各地区旅行。她会自己走过一段路，遇到事件和角色，
最后带着明信片和旅途记录回家。

========================================================
怎么玩
========================================================

直接双击“开始游戏.html”即可运行，推荐使用 Chrome 或 Edge。

也可以使用开发服务器：

    npm install
    npm run dev

首次进入会确认游戏所在地为挪德卡莱。游戏核心玩法不要求联网，
进度保存在当前浏览器设备中。关闭页面不会停止已经开始的旅行和作物生长。

========================================================
家园
========================================================

哥伦比娅会在家园中移动，在不同状态下阅读、休息、准备食物、玩玩具、
照看田地或等待归来。点击她会触发当前状态对应的反应和气泡台词。

家园底部可以进入：田地、厨房、玩具、仓库、成就、聊天、明信片和设置。

========================================================
田地
========================================================

田地是独立的 4:3 场景，共有六块田：四块旱田和两块水田。
哥伦比娅在家时进入田地，她也会跟着来到田地场景。

点击对应田块可以播种。作物按真实时间生长，成熟后可以收获；
收获的作物可用于厨房料理，也有几率获得稀有道具。

========================================================
旅行
========================================================

点击“送她出门”，可以选择随机探索、指定提瓦特地区或指定大致方向。
料理和稀有道具会影响旅行预算。旅途中可能遇到补给、挫折、改道、
风景或其他角色；路程不足时也可能提前返回，这同样会生成旅行记录。

她回来后会带回一张明信片。明信片会记录目的地、天气、时段、同行角色、
旅途日志和沿途见闻，并保存到明信片册中。

========================================================
来访角色与互动
========================================================

部分角色会来到家园短暂来访。最多同时有一位客人；客人会在家中活动、
玩玩具、阅读或与哥伦比娅打招呼。客人的停留时长可以在设置中调整。

========================================================
命令栏
========================================================

按键盘“~”或“`”可以打开命令栏；手机和平板可以点击画面右下角的“~”。

常用命令：

    help                         查看命令摘要
    status                       查看当前状态
    trip region 须弥 柯莱        指定地区并指定偶遇角色
    trip finish                  立即完成当前旅行
    visitor 派蒙                指定角色来访
    encounter 赛诺              指定下次旅行遇见的角色
    event aurora                 指定下次明信片见闻
    farm plant dry1 potato       在指定田块播种
    farm ready dry1              立即催熟
    farm harvest dry1            收获成熟作物

完整命令、地区、角色、作物和事件清单见“命令栏使用说明.txt”。

========================================================
存档与注意事项
========================================================

· 进度保存在当前浏览器设备中，清理浏览器站点数据可能删除存档。
· 可以通过设置中的“导出存档”备份 JSON 文件。
· 当前版本不要求 API Key，不连接云存档，也不依赖在线 AI。
· 命令栏中的 reset confirm 会清空本地进度，请谨慎使用。
