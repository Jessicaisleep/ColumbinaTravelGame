《哥伦比娅的旅行》命令栏使用说明
====================================

用途
----
本命令栏用于本地开发、内容检查和快速测试。命令会直接操作当前设备上的本地存档，
不会联网，也不会上传数据。执行 reset、trip cancel 等命令前请先阅读对应说明。

打开与关闭
----------
1. PC 键盘按 ` 或 ~（键盘左上角 Esc 下方的反引号键）打开/关闭命令栏。
2. 手机、平板或没有该按键的设备，可以点击画面右下角圆形“~”按钮。
3. 按 Esc、点击右上角“×”或输入 close 关闭命令栏。
4. 按 Enter 执行；方向键 ↑ / ↓ 可浏览本次打开游戏后的命令历史。
5. 参数既可以写 ID，也可以写中文名；含空格的参数请用英文双引号包裹。


一、基础命令
------------
help
commands
?
  显示命令摘要，三条命令效果相同。

clear
  清空命令栏输出，不改游戏数据。

close
exit
  关闭命令栏。

status
  查看当前场景、居家状态、来访角色、探索倒计时、下一次强制事件和明信片数量。


二、界面命令
------------
home                 回到家园
farm                 进入独立田地界面
kitchen              打开厨房

三、探索命令
------------
trip random [偶遇角色]
  开始随机探索。可选的最后一个参数会强制本次遇见指定角色。
  示例：trip random 柯莱

trip region <地区ID或名称> [偶遇角色]
  开始指定地区探索。命令栏会提供调试路粮并屏蔽随机改道，保证抵达指定地区；
  如果同时通过 journey-event 强制“失足”或“改道”事件，则优先保留事件的正常结果。
  示例：trip region sumeru
  示例：trip region 须弥 柯莱

trip region list
  列出全部地区。

trip bearing <n|s|e|w|c|any> [偶遇角色]
  按方向开始探索。n北、s南、e东、w西、c中部、any随机。
  也可写：北、南、东、西、中、随机。
  示例：trip bearing n
  示例：trip bearing 南 赛诺

trip finish
  立即完成当前探索，走正常结算流程并打开结果，不会伪造明信片。

trip finish <秒数>
  将当前探索的剩余时间调整为指定秒数。
  示例：trip finish 10

trip result
  打开最近一次已经完成的探索结果。

trip cancel confirm
  取消当前探索。已消耗的料理和稀有道具不会返还。


四、指定偶遇角色
----------------
encounter <角色ID或名称>
  指定下一次探索遇见的角色；设置只使用一次，探索开始后自动清除。
  示例：encounter collei
  示例：encounter 柯莱

encounter random
encounter clear
encounter off
  清除指定角色，下一次探索恢复随机偶遇。

encounter list
  列出全部可偶遇角色。

说明：也可以直接在 trip 命令最后写角色，例如 trip region 须弥 柯莱。


五、指定明信片见闻事件
----------------------
event <事件ID或名称>
  指定下一次探索的明信片见闻；设置只使用一次。
  示例：event aurora
  示例：event 看见了极光

event random
event clear
event off
  清除指定见闻，恢复随机。

event list
  在命令栏列出全部通用与地区专属明信片见闻。

注意：地区专属见闻必须与本次目的地一致。例如 sumeru_play_0 应配合须弥探索使用。


六、指定旅途过程事件
--------------------
journey-event <事件ID或名称>
  指定下一次探索的第一个路途过程事件；设置只使用一次。
  示例：journey-event meet_1
  示例：journey-event 在水边失足

journey-event random
journey-event clear
journey-event off
  清除指定过程事件，恢复随机。

journey-event list
  列出全部旅途过程事件。

过程事件仍会走正常路线模拟。例如“在水边失足”可能导致提前返程，“被邀请前往另一处”
可能触发改道；需要同伴的事件会先从正常偶遇角色池补充同伴。


七、指定角色来访
----------------
visitor <角色ID或名称>
  让指定角色立即来到家园。
  示例：visitor paimon
  示例：visitor 派蒙

visitor random
  从可来访角色池随机选择一位立即来访。

visitor clear
visitor off
  让当前来访角色离开。

visitor list
  列出全部可来访角色。


八、哥伦比娅状态与互动
----------------------
state <状态ID或名称>
  立即切换哥伦比娅的居家状态。
  示例：state read
  示例：state 阅读

state random
  随机切换一个居家状态。

state list
  列出全部居家状态。

poke
  触发一次点击哥伦比娅的互动。

bar
  切换家园/田地底部菜单的展开与收起状态。

rotate
  再次触发移动端“建议横屏”提示；宽屏设备不会显示提示。


九、田地命令
------------
farm
  进入田地界面。

farm list
  列出所有田块和作物 ID。

farm status
  查看六块田的空闲、生长或成熟状态。

farm plant <田块ID或名称> <作物ID或名称>
  在指定空田播种。旱田只能种旱田作物，水田只能种水田作物。
  示例：farm plant dry1 potato
  示例：farm plant 楚此诸田·一 金鱼草

farm ready <田块ID或名称>
  立即催熟指定田块已有的作物。

farm ready all
  立即催熟所有已播种田块。

farm harvest <田块ID或名称>
  收获指定的成熟田块。

farm harvest all
  收获所有成熟田块。


十、存档、素材与设置命令
------------------------
save
  立即保存当前进度。

export
  导出当前存档 JSON 文件。

assets
probe
  显示素材总数、已加载数、失败数和失败项；两条命令效果相同。

sound on
sound off
  开启或关闭音效并保存设置。

demo
  写入项目内置试玩数据，用于快速检查仓库、玩具、田地和明信片。
  该命令会改变当前存档，建议先使用 export 备份。

reset confirm
  清空全部本地进度。此操作不可撤销，必须完整输入 confirm。

十九、组合示例
--------------
指定去须弥并遇见柯莱：
trip region 须弥 柯莱

指定去挪德卡莱、看见极光并在 5 秒后完成：
event aurora
trip region nod_krai
trip finish 5

指定第一段遇到同伴，并指定该同伴为赛诺：
encounter 赛诺
journey-event meet_1
trip region 须弥

让派蒙来访，并把哥伦比娅切换到阅读状态：
visitor 派蒙
state 阅读

在第一块旱田种土豆、立即催熟并收获：
farm plant dry1 potato
farm ready dry1
farm harvest dry1

快速完成当前探索并查看结果：
trip finish
trip result


错误提示说明
------------
“找不到……”：请使用对应的 list 命令检查 ID 或中文名。
“已有探索正在进行”：先等待、使用 trip finish，或确认后使用 trip cancel confirm。
“这块地种不了这个”：旱田和水田的作物类型不匹配。
“这块田还种着东西”：先等待成熟并收获，或换另一块空田。
“当前没有进行中的探索”：需要先使用 trip random / region / bearing 开始探索。
